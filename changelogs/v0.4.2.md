# v0.4.2 — iOS Swift Header Visibility Fix

**Release Date:** 2026-09-04

Patch release exposing native headers to Swift for background upload integration in host apps.

---

## 🛠️ Fixes

### iOS Swift Header Visibility in Podspec
- **File:** `Transferkit.podspec`
- **Issue:** All headers were previously marked private (`s.private_header_files = "ios/**/*.h"`), preventing Swift (`import Transferkit`) from seeing `TKUploadManager` and causing `Cannot find 'TKUploadManager' in scope` when configuring `AppDelegate.swift`.
- **Fix:** Exposed `TKUploadManager.h` as a public header (`s.public_header_files = "ios/upload/TKUploadManager.h"`).
