# v0.4.1 — iOS Objective-C++ Compilation Fix

**Release Date:** 2026-09-03

Patch release resolving a native compiler error on iOS when building in React Native host apps.

---

## 🛠️ Fixes

### iOS Objective-C++ Type Conversion Fix
- **File:** `ios/upload/TKUploadManager.mm`
- **Issue:** When building with Clang under Objective-C++ (`.mm`) compilation rules, passing `headerData.bytes` and `closingData.bytes` (`const void *`) directly into `-[NSOutputStream write:maxLength:]` caused:
  ```text
  Cannot initialize a parameter of type 'const uint8_t * _Nonnull' (aka 'const unsigned char *') with an rvalue of type 'const void *'
  ```
- **Fix:** Explicitly cast buffer pointers to `(const uint8_t *)` matching `NSOutputStream`'s parameter type signature.
